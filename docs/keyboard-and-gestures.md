# Keyboard & Navigation Guide

`yfiles` maps standard desktop file manager keybindings (KDE Dolphin & Windows Explorer) to terminal environments:

## 1. Navigation & Breadcrumbs
- `Up` / `Down` / `Left` / `Right`: Move selection in grid/list.
- `Enter`: Open selected file or descend into folder.
- `Backspace` / `Alt+Up`: Ascend to parent directory.
- `Ctrl+L` / `Alt+D`: Focus the path address bar for manual entry.
- `Ctrl+H`: Toggle hidden files (`.` dotfiles) visibility.

## 2. Selection & Views
- `Ctrl+A`: Select all items in current directory.
- `Space`: Toggle selection of active item without navigating.
- `Ctrl+1`: Details table view.
- `Ctrl+2`: Compact list view.
- `Ctrl+3`: Icon / Grid view.
- `F3`: Toggle split dual-pane view.

## 3. File Operations
- `F2`: Inline rename.
- `Delete`: Move selected items to trash.
- `Shift+Delete`: Permanently delete with confirmation prompt.
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V`: Copy, cut, and paste.
- `F4`: Open an interactive terminal pane in the current folder.
